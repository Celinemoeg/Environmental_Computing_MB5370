# Environmental_Computing_MB5370

This repository contains scripts, spatial analyses, and web applications developed for **Module 05: Global Scale Analysis** as part of *MB5370: Techniques in Marine Biology 1 (Environmental Computing)* at James Cook University.

## Module Overview
This module focuses on cloud-based geospatial computing in **Google Earth Engine (GEE)** using JavaScript to analyse global-scale remote sensing and environmental datasets, track progress toward global conservation targets, and build a interactive geospatial web app.

---

## Workshops & Practicals

* **Workshop 1: A Guided Tour of Earth Engine**
  * Introduction to the GEE Code Editor, JavaScript fundamentals (variables, lists, objects, functions), data catalogue navigation, and map visualisation.
  * Note: for me this one got split into two files, the first focusing on the basic java script, and the second the map visualisation.
* **Workshop 2: Filters and Computation**
  * Applying metadata and spatial filters, image thresholding, conditional logic, and running region and image reducers at global scales.
* **Workshop 3: Nightlights in Coastal Ecoregions**
  * Analysing global coastal change using night-time lights imagery and vector ecoregions, and scaling workflows for export.
* **Workshop 4: Allen Coral Atlas**
  * Mapping functions across coral reef research station locations, analysing benthic/geomorphic coral data, and exporting outputs locally.
* **Additional Independent Tutorials**
  * Exploratory workflows covering Forest Analysis and Dynamic World land cover datasets.
